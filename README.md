# Moosh GFs Tornados (Forge 1.20.1)
Komutlar (OP gerekir): /mooshgfstornado f1 .. f5 | dominator1..dominator4 | dominator <1-4> | remove
Dominator: spawn egg veya komut; sağ tık = bin, WASD = sür (4 koltuk). Dominator 1-4 sırasıyla F2/F3/F3/F4'e kadar savrulmaz.
## Jar'ı derleme (MDK/IDE gerekmez)
1) github.com'da boş bir repo aç, bu klasörün İÇİNDEKİLERİ yükle (Add file > Upload files).
2) Actions sekmesi > "Build jar" > bitince Artifacts > mooshgfstornado-jar indir.
Ya da bilgisayarında Java 17 + Gradle 8.8 varsa: gradle build  ->  build/libs/
